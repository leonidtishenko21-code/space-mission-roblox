## How to run

1. Install [Roblox Studio](https://create.roblox.com/).
2. Download [`SpaceMission.rbxl`](SpaceMission.rbxl) from this repository.
3. Open it in Roblox Studio (File → Open from File).
4. Press Play.

The source code is in the `src/` folder and follows the Roblox Studio structure. Files ending in `.server.lua` are Scripts, files ending in `.client.lua` are LocalScripts, and plain `.lua` files are ModuleScripts.

## Controls

| Key | Action |
|---|---|
| E | Use the builder or the derrick panel, leave the capsule after landing, pick up a sample |
| Enter | Launch |
| W A S D, Q E | Turn the rocket, roll |
| Shift / Ctrl, Z / X | Throttle up / down, full / zero |
| Space | Separate a stage, jump / jetpack on the surface |
| P | Parachute / autoland |
| T, R, G | SAS, retrograde, nozzle to planet |
| V, L, F, K | Cockpit view, headlamp, get back into the capsule, take off the suit |
